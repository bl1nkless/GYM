# GymTrack 🏋️

Умный трекер тренировок с аналитикой по мышечным группам и рекомендациями по весам.

## Возможности

- 📱 **PWA** — устанавливается на телефон как приложение
- 🏋️ **Логирование тренировок** — упражнения, подходы, веса, повторения
- 💡 **Умные рекомендации** — вес на основе прошлых ощущений (Легко/Нормально/Тяжело)
- 📊 **Аналитика по мышцам** — когда последний раз тренировал, сколько тренировок за период
- 🔐 **Авторизация** — регистрация и вход по email

## Быстрый старт

### 1. Создай проект в Supabase

1. Зайди на [supabase.com](https://supabase.com) и создай новый проект
2. Перейди в **Project Settings → API** и скопируй:
   - `Project URL`
   - `anon public` key

### 2. Настрой переменные окружения

Создай файл `.env.local` в корне проекта:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Настрой базу данных

1. В Supabase открой **SQL Editor**
2. Скопируй содержимое файла `supabase/schema.sql`
3. Выполни SQL — это создаст все таблицы, политики безопасности и базовые упражнения

### 4. Включи авторизацию по Email

1. В Supabase перейди в **Authentication → Providers**
2. Убедись, что **Email** включён
3. (Опционально) Отключи подтверждение email для тестирования:
   - **Authentication → Settings → Email Auth → Confirm email** → OFF

### 5. Запусти проект

```bash
# Установи зависимости
npm install

# Запусти dev-сервер
npm run dev
```

Открой http://localhost:3000

## Основные флоу

### Логирование тренировки

1. Нажми **+** (FAB кнопка)
2. Добавь упражнения через поиск или создай своё
3. Введи подходы (вес подставляется автоматически на основе истории)
4. Отметь ощущение: **Легко** / **Нормально** / **Тяжело**
5. Нажми **Готово**

### Рекомендации по весу

Система запоминает твои ощущения:

- **Легко** → в следующий раз предложит +2.5 кг
- **Нормально** → вес останется тем же
- **Тяжело** → вес останется тем же (можно снизить)

### Аналитика

Страница показывает для каждой мышечной группы:

- Когда последний раз тренировал
- Сколько тренировок за выбранный период
- Сколько упражнений было в последней тренировке

Индикаторы:

- 🟢 Зелёный — тренировал ≤ 3 дня назад
- 🟡 Жёлтый — 4-7 дней назад
- 🔴 Красный — > 7 дней назад
